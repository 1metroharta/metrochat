# Firebase Realtime Database Rules — MetroChat

Файл `database.rules.json` собран на основе правил, присланных владельцем проекта. Он сохраняет совместимость со старой клиентской логикой MetroChat и не меняет структуру базы.

## Важно перед публикацией
Эти правила **не являются полностью защищёнными для публичного запуска**. В текущей архитектуре клиент напрямую меняет общие узлы `messages`, `stories`, `gift_inventory`, `gift_transfers`, `gift_wallet`, `channels`, `calls` и другие. Простые правила RTDB не могут безопасно подтверждать оплату или защищать баланс, если клиент сам может записывать баланс. Для этого операции с деньгами/подарками нужно перенести в Cloud Functions с проверкой участников и транзакциями на сервере.

Не ужесточал доступ к `messages`, `user_chats`, `stories` и подаркам наугад: без подтверждённой схемы участников это может снова скрыть чаты и истории. Перед production-публикацией нужен тестовый Firebase-проект и миграция денежных операций.

Новые пользовательские сценарии ботов сохраняются внутри `user_settings/{uid}/custom_bots`; действующее правило `user_settings/$uid` уже ограничивает запись владельцем.

## Установка
Firebase Console → Realtime Database → Rules → заменить содержимое JSON-файлом `database.rules.json` → сначала проверить в тестовом проекте → Publish. Не публикуйте поверх рабочего проекта без резервной копии текущих Rules.
