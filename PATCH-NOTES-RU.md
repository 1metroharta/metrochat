# MetroChat 4.2 — единый патч

## Исправлено в клиенте
- Ошибка чтения `gift_wallet` больше не отображается как нулевой баланс. Покупки за УМ блокируются, пока баланс не прочитан.
- Загрузка подарков различает отсутствие записей и отказ Firebase в доступе.
- Бизнес-доступ сверяется с реальным флагом `galochka/{uid}/confirmed`, как и галочка в профиле; проверка перечитывается из базы, если локальный статус ещё не загружен.
- У папок чатов отдельное локальное хранилище на аккаунт; синхронизация в `user_settings/{uid}/folders` сообщает ошибку правил вместо тихого сбоя.
- Исправлена прокрутка настроек: при обновлениях сохраняется позиция прокрутки на текущей странице настроек.
- Редактор оформления упрощён: однотонные цвета, простые переключатели, выбор шрифта/иконки/свайпа; убраны прежние элементы настройки градиентов и размытия. Старые настройки градиента предварительно копируются в `mc_ui_prefs_backup_4_2`, затем удаляются из активных предпочтений.
- Обновлена карточка кошелька и отображение подарков в профиле.
- Ошибка чтения `user_chats` теперь видна пользователю; история сообщений не удаляется из-за ошибки чтения.
- Metro AI сначала обращается к приватной Firebase Cloud Function с OpenAI Responses API и моделью `gpt-6.2-sol`; старый сторонний endpoint остаётся временным fallback до развёртывания функции.
- Service worker поднят до v4.2, чтобы обновить старую оболочку.

## Что требует доступа владельца проекта
- Firebase Rules надо восстановить/объединить с полным прежним набором. На скриншоте виден неполный фрагмент, поэтому в архиве нет опасного шаблона, который заменил бы все production-правила. Читай `FIREBASE_RULES_RECOVERY_RU.md`.
- Для настоящего Metro AI нужно добавить секрет `OPENAI_API_KEY` и развернуть Cloud Function через `DEPLOY_METRO_AI.bat`. Без секретного ключа/развёртывания функция не может обращаться к OpenAI; клиент временно использует резервный endpoint.
- GitHub Pages сам по себе не разворачивает Firebase Cloud Functions; они развёртываются отдельно через Firebase CLI.

## Данные и безопасность
Этот патч не очищает Realtime Database, не удаляет аккаунты/чаты/истории/подарки и не записывает нулевой баланс при ошибке чтения. Он не открывает всем пользователям запись в чужие кошельки.
