# MetroChat 4.4 — исправления и статус

## Изменения в этой сборке
- Сохранение выбранной скорости 1× / 1,5× / 2× для голосовых сообщений и видеокружков, в том числе если скорость выбрана до начала воспроизведения.
- Мобильное удержание строки чата для меню быстрых действий (ранее добавлено в патче 4.4).
- Конструктор AI-ботов: добавлены условия вида `фраза => ответ`; можно задать кнопки в формате `название | текст для отправки`. Условия выполняются до обращения к ИИ.
- Сценарии ботов сохраняются в `user_settings/{uid}/custom_bots`, доступ к узлу остаётся владельцу аккаунта.
- Убран старый редактор градиентных обоев из дополнительных настроек; оставлены отдельные настройки оформления профиля с десятью сплошными цветами.
- Сохранены регистрационный экран, отдельные вход/регистрация, прогресс, финальная анимация и предложение настроить уведомления/установку/2FA, которые уже были в исходной сборке 4.3.
- Подготовлен отдельный `database.rules.json` на основе присланных правил и файл с предупреждениями по безопасности.

## Ограничения проверки
- Проверен синтаксис JavaScript встроенных скриптов и валидность JSON.
- Не выполнено подключение к реальному Firebase-проекту, проверка API-ключа, публикация Cloud Function, браузерные e2e-тесты и тесты на физических телефонах.
- AI-ответы требуют развёрнутой Cloud Function `metroAi` и секрета `OPENAI_API_KEY`. Если сервис продолжает показывать ошибку, проверьте развёртывание функции и логи Firebase Functions.
- Правила сохраняют совместимость, но не являются полностью защищёнными от злоупотреблений балансом/подарками; подробности — `FIREBASE_RULES_README_RU.md`.
- В редакторе создания истории оставлена кнопка «Все» как настройка аудитории («Кто видит»), а не вкладка историй. Удалять её означало бы менять приватность публикации.
