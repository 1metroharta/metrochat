# Установка патча MetroChat 4.2 (Windows)

1. Распакуйте архив в отдельную папку. Сначала сделайте копию текущей папки сайта/проекта.
2. В корневой папке проекта замените `index.html` файлом `MetroChat-4.2/index.html` из архива.
3. Замените корневой `sw.js` файлом из архива.
4. Скопируйте папку `functions` и файлы `firebase.json`, `.firebaserc` в корень проекта. Если в проекте уже есть `functions` или `firebase.json`, сначала сохраните их копии и объедините, не перезаписывайте неизвестные настройки.
5. Файлы `index.before-4.2.html`, `PATCH-NOTES-RU.md` и `FIREBASE_RULES_RECOVERY_RU.md` оставьте рядом как резервную копию и инструкции.
6. Опубликуйте обновлённый сайт обычным способом, которым вы обновляете GitHub Pages. Патч не отправляет изменения в GitHub автоматически.
7. Чтобы включить новый Metro AI, на Windows запустите `DEPLOY_METRO_AI.bat` из корня проекта. Нужны Firebase CLI, Node.js 20 и права на развёртывание Cloud Functions в проекте. Скрипт попросит секретный ключ OpenAI; вставляйте его только в этот запрос, не в `index.html` и не в GitHub.

**Не заменяйте Firebase Realtime Database Rules этим архивом.** По присланному скриншоту нельзя безопасно восстановить полные правила; сначала прочитайте `FIREBASE_RULES_RECOVERY_RU.md`.

Для отката верните прежние `index.html` и `sw.js` из резервной копии, которую сделали перед установкой. `index.before-4.2.html` — копия именно того `index.html`, поверх которого собран этот патч.
