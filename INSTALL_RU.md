# Установка MetroChat 4.4 (Windows)

1. Сделайте резервную копию текущей папки проекта и текущих Firebase Realtime Database Rules.
2. Из папки `MetroChat-4.4` замените `index.html` и `sw.js` в корне сайта.
3. Объедините `functions`, `firebase.json` и `.firebaserc` с вашим проектом. Если у вас есть собственные Cloud Functions или настройки Firebase, не затирайте их — объедините вручную.
4. Для Metro AI и AI-ботов нужны Node.js 20, Firebase CLI, права на Cloud Functions и секрет `OPENAI_API_KEY`. Запустите `DEPLOY_METRO_AI.bat`; он запросит ключ и развернёт функцию `metroAi`. Не вставляйте ключ в HTML или GitHub.
5. Файл `database.rules.json` содержит правила, основанные на присланной вами версии. Сначала проверьте их в тестовом Firebase-проекте. Только после резервной копии и проверки запускайте `DEPLOY_RULES.bat` (публикует правила в выбранный Firebase-проект).
6. Опубликуйте сайт и обновите его через Ctrl+F5.

## Важные ограничения
- Архив не подключается к вашему Firebase и не публикует сайт автоматически.
- AI работает только после успешного развёртывания `metroAi` и настройки секрета `OPENAI_API_KEY`.
- Текущие RTDB Rules сохраняют совместимость с прежней клиентской архитектурой, но ещё не обеспечивают серверную защиту балансов/подарков. Перед публичным запуском денежные операции нужно перенести в Cloud Functions. Подробности — `FIREBASE_RULES_README_RU.md`.
- Проверены синтаксис JavaScript и JSON; реальное поведение нужно протестировать в вашем браузере и тестовой базе Firebase.
